\section{Application: Criticality and Trade-Disruption Analysis}
\label{sec:application}

The MEKH is built to be used. This section gives the two analyses the institute's analysts run on it: which materials are structurally critical to a mineral's downstream reach, and what a concentrated exporter's withdrawal would remove. Both are computed on the MEKHs evaluated in Section~\ref{sec:evaluation}, with material codes as generated.

\subsection{Criticality by reachability}
Each \tool{} is constructed for a base material, e.g., boron, which we denote $m_{base}$; the set of materials that $m_{base}$, in combination with other raw materials, can be transformed into is its \textit{reach}. The criticality of any other material is the reduction in the reach of $m_{base}$ when that material is removed; from a policy perspective, removal could correspond to banning the production and use of that material, and criticality quantifies the cascading effect.

\begin{definition}
\label{def:pre}
\textbf{Precursor Set.}
Given a \tool{} $\Hcal(M, E)$, where each hyperedge $e \in E$ has a source set $e_s$ and a target set $e_t$, we define the precursor set $\mathtt{Pre} = \bigcup_e e_s - \bigcup_e e_t$ to be the set of materials which appear only in hyperedge sources.
\end{definition}

\begin{definition}
\label{def:reach}
\textbf{Reachable set.}
Given a \tool{} $\Hcal(M, E)$ and a set $m_{start} \subseteq M$, a material $m_i$ is considered reachable if it is in the
target set of a hyperedge whose source set contains only materials that are in $m_{start}$ or are themselves reachable. The 
reachable set, $R(m_{start}, \Hcal)$ is the set of all nodes that are reachable from $m_{start}$ in $\Hcal$.
\end{definition}

\begin{definition}
\label{def:criticality}
\textbf{Criticality.}
Given a \tool{} $\Hcal(M, E)$ and a set $m_{start} \subseteq M$, the criticality of a material $m_i$ is defined as, 
\begin{align}
\nonumber
c(m_i, m_{start}, \Hcal) = |R(m_{start}, \Hcal)| - |R(m_{start}\setminus m_i, \Hcal \setminus m_i)|,
\end{align}
i.e., it is the reduction in the 
size of the reachable set when $m_i$ is removed.
\end{definition}

In our analysis of criticality, we always set $m_{start} = m_{base} \cup \mathtt{Pre}$. For each \tool{}, we compute $c(m_i, 
m_{start}, \Hcal) \forall m_i \in M$ (except for $m_{base}$ itself). For a \tool{}, its \textbf{criticality list} is the set $M$ of 
its materials, ordered from most critical to least critical. Note that this list is partially ordered, as several materials can
have the same criticality.

The vertices are the registered HS-6 materials (Section~\ref{sec:mekh}); untyped materials and unregistered codes are dropped from hyperedges, and a hyperedge left without outputs is dropped. Three modelling rules determine the numbers. (i)~A hyperedge with no input among the vertices (\CritSourcelessEdgesBoron{} of boron's \CritEdgesBoron{}, mostly extraction steps whose inputs are untyped) fires unconditionally, because the empty source set satisfies Definition~\ref{def:reach}; this is why $\mathtt{Pre}$ is small (\CritPreBoron{} material for boron). (ii)~Removing $m_i$ bans it: it leaves $m_{start}$, every hyperedge that consumes it is disabled, and it is never counted as reachable, but the co-products of hyperedges that make it are still produced. (iii)~$m_{base}$ is the refined, unwrought element: HS \CritBaseCodeBoron{} for boron, \CritBaseCodeCobalt{} for cobalt, \CritBaseCodeGallium{} for gallium, and \CritBaseCodeGermanium{} for germanium.

No single removal costs much of the reach: the most critical material for boron, \CritTopNameBoron{} [\CritTopCodeBoron], removes \CritTopBoron{} of \CritReachBoron{} reachable materials. The top-ranked materials are bulk reagents and utilities---acids, salt, water, chlorine, hydrogen, coal---rather than mineral-specific intermediates; boron's ore, \CritThirdNameBoron{}, is the exception. Rule (i) matters. If hyperedges with no registered input are dropped instead, their products become precursors unless another hyperedge makes them, and $|R|$ shrinks (boron \CritReachBoron{}$\to$\CritReachNoSourcelessBoron{}, cobalt \CritReachCobalt{}$\to$\CritReachNoSourcelessCobalt{}, gallium \CritReachGallium{}$\to$\CritReachNoSourcelessGallium{}, germanium \CritReachGermanium{}$\to$\CritReachNoSourcelessGermanium{}). The top material then changes for boron (\CritTopNameNoSourcelessBoron{} with criticality \CritTopNoSourcelessBoron{}, tied with a second water code) and gallium (\CritTopNameNoSourcelessGallium{} with \CritTopNoSourcelessGallium{}), and stays the same for cobalt and germanium. Criticality values are therefore conditional on how processes with untyped inputs are treated.

\subsection{Disruption analysis with UN Comtrade}
UN Comtrade~\cite{UNComtrade2024} records bilateral trade by HS code; because MEKH vertices are HS-6 codes, the join is by code. We use the 2024 bilateral flows as mirror data: imports recorded by each reporter are attributed to the partner as exporter, and a code's global exports are the sum over all flows. Aggregate reporters (EU, World) are excluded to avoid double counting; aggregate partner codes (regional residuals, bunkers, free zones, areas not elsewhere specified) stay in the total but cannot be the top exporter. A code is \emph{dominated} if its top exporter supplies at least \DisruptThreshold{} of global exports. For each dominated code we simulate that exporter halting it: the code is removed, every hyperedge consuming a removed material is disabled, and a material all of whose producing hyperedges are disabled is removed in turn, until nothing changes; a material that no hyperedge produces is removed only directly. Its \emph{dependents} are the materials removed besides the code itself.

The other \DisruptLocalBoron{} dominated codes have no dependents. The pattern holds for the other \tool{}s: gallium has \DisruptDominatedGallium{} dominated codes, of which only \DisruptMaxNameGallium{} (\DisruptMaxSupplierGallium{}, \DisruptMaxShareGallium{}) cascades, to \DisruptMaxDependentsGallium{} code; germanium has \DisruptDominatedGermanium{} and cobalt \DisruptDominatedCobalt{}, none cascading. Some rows inherit the code errors of Section~\ref{sec:evaluation}: the germanium \tool{} assigns quicklime the code that the gallium \tool{} uses for gallium oxide. Concentrated supply is thus common but mostly local, and the \tool{} isolates the one boron intermediate, refined borax, whose loss propagates.

\subsection{Use in practice}
The pipeline's outputs are used in three ways at the institute. (1)~HS-code groupings derived from MEKHs define the raw and refined material baskets of a separate US--China microelectronics vulnerability analysis (in submission). (2)~The pipeline's material-classification agent, run in a lightweight export mode without full process discovery, maps each of the 73 USGS mineral commodities to its HS-6 code bucket (426 codes in total); joined to UN Comtrade US-import values for 2017--2025, these buckets drive the trade-disruption view of an interactive dependency-network explorer used by researchers at the institute, a companion to a separate top-down technology-decomposition system (in submission). That view computes, per commodity, the import value lost when the top $k$ exporters are removed and a supplier lock-in count, following the multiplex trade-network metrics of the vulnerability analysis in (1). (3)~Full MEKHs are used directly, as in this section, for the mineral-specific cascade questions that neither the commodity buckets nor the top-down decomposition can answer. Uses (1) and (2) depend only on the HS typing; use (3) also depends on the auditable references.
